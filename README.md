One word for the whole internet: **Bickerbazaar**.

A bicker + bazaar portmanteau: the internet as one noisy global market where every stall is also an argument. Funny by itself, true about the whole internet (commerce + speech + arguing), and surprising — not the first obvious word anyone reaches for.

Entry for the [The Internet in One Word bounty](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) on make.fun.
